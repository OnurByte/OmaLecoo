# Image sources

- `gk301-vendor.png`: unmodified `img_keboard_demo.png` from the original
  Lecoo GK301 Windows utility, retained locally under `reference/windows/`.
  Vendor artwork depicts the supported keyboard; it is not covered by this
  repository's MIT code licence.
- `omalecoo-banner.svg` / `.png`: OmaLecoo banner, using that vendor keyboard
  image with the existing dark background, RGB glow and wordmark. The SVG
  embeds the PNG so it renders without external dependencies.
- `panel-lighting.png`: actual installed OmaLecoo Lighting panel, captured on
  Omarchy on 22 October 2026 and cropped to the panel. No controls were redrawn.
